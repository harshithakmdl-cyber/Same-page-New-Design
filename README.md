# Project 17: Same Page, New Design

## Files
- `before.html`: plain page before applying design.
- `after.html`: redesigned responsive page with the same visible copy.
- `style.css`: visual styling used by `after.html`.
- `screenshots/`: assignment reference pictures supplied by the student.

## Three design changes and why they help
1. **Grouped content into clear cards**: event, chai shop, and classes are visually separated, so visitors can scan each offer quickly.
2. **Added stronger typography and contrast**: larger headings, small category labels, and contrasting buttons make important information easier to notice.
3. **Made the layout responsive**: flexible chips, fluid page width, and a mobile breakpoint keep the page readable on phones without horizontal scrolling.

## How to view
Open `before.html` or `after.html` in a browser. The redesigned page loads `style.css` from the same folder.
